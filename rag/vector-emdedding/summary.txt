Vector database and Embeddings

### Vector Database
-  a vector database encodes information as vectors in a multi-dimensional space to perform high-efficent queries based on similarity.
    [vector - dimensionality - similarity search]

1. Vector -> Direction {toward direction} -> Magnitude -> distance

### Why? 

80% or more data is unstructed - contains images,videos,text,audio,files etc.. ->  tunred into -> vectors [-223.23. 0.56]

1. efficient representation of complex data
2. Enabling similarity search
3. Leveraging Machine Learing Models
4. Optimizing performance and scalability
5. Improving user experience

## Embeddings vs vectors -> refers to the same thing [embeddings are vectors, not all vectors are embeddings]

1. vectors -> are generic and used for a wide array of applications (handle numerival computations)
2. Embeddings -> map raw data into a vector space (preserves semantic relationships- meaning)


### Vector database use cases : 

1. image retrieval & similarity search
2. recommendation systems
3. Natural lanuguage processing
4. Fraud detection
5. BioFormatics
